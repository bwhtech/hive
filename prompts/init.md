## Frontend Setup

Run this in a temp directory: 

```sh
yarn dlx shadcn@latest create --preset "https://ui.shadcn.com/init?base=base&style=maia&baseColor=gray&theme=amber&iconLibrary=hugeicons&font=geist&menuAccent=subtle&menuColor=inverted&radius=small&template=vite&rtl=false" --template vite
```

Then copy relevant setup / settings in out frontend project so we have a nice Frontend setup.

Then setup frappe-react-sdk (must read their README: https://github.com/The-Commit-Company/frappe-react-sdk) with latest React Router

Then test using agent browser.
